To grant a user the read-only manager layout:

1. Go to *Settings > Users & Companies > Groups*.
2. Open the *Locations Report: Manager Layout (Read-only)* group.
3. Add the relevant users.

The group implies *Inventory / User* and *Inventory Reporting Access*
(`stock_reporting_access.group_stock_reporting_user`), so assigned users can
reach the *Inventory > Reporting* menu and open the Locations report without any
further configuration. Stock managers always keep the editable manager layout
regardless of this group.
